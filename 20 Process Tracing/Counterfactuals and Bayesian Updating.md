# Counterfactuals and Bayesian Updating

Counterfactuals belong upstream in theory testing:
```text
ontology -> candidate models -> counterfactual interventions -> discriminating predictions -> observable implications -> evidence search
```

Short loop: new evidence → Bayesian update → next best evidence → update.

Long loop: anomaly → abduct new model → revise graph/ontology → new predictions → test.

Hoop tests, smoking guns, doubly decisive evidence, and straws in the wind can be interpreted as qualitative likelihood-ratio structures. Evidence dependence must be modeled to avoid double-counting multiple traces generated by a common source/process.
