# Induction, Abduction, Deduction

- **Induction:** observations → empirical regularities. Regularities can include frequency, sequence, thresholds, distributions, associations, and invariances; they are not limited to statistical correlation.
- **Abduction:** observations/regularities → candidate causal model. Abduction expands the hypothesis/model class.
- **Deduction:** causal model → predicted observations.

```text
observations -> induction -> abduction -> deduction -> targeted testing -> revision
```

Bayesian updating over a fixed hypothesis set does not itself generate a new H4; abduction is the model-generation step.
