# State Transition Causal Ontology

A useful decomposition is:
```text
world state -> information generation -> transmission -> perception -> belief update -> valuation -> option generation -> decision rule -> choice -> implementation -> new world state
```

Many entities can mathematically be collapsed into an enlarged state, but this can be analytically destructive. Keep distinct: state/configuration; transition law/mechanism; action/control input; exogenous input; observation/measurement.

Two mechanisms can produce the same state sequence through different transition laws. Causal analysis therefore cannot identify mechanisms merely with sequences of states.
