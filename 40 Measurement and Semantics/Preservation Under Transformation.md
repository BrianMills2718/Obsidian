# Preservation Under Transformation

A unifying pattern is:
```text
source structure -> transformation -> target structure
```
then ask: **what must be preserved for the downstream inference or claim to remain licensed?**

Examples: world → measurement; micro-model → macro-model; semantic IR → DAG; model → alternate representation; case → general theory; factual world → counterfactual world; ontology v1 → ontology v2; source document → evidence object.

Candidate abstraction:
```text
A --T--> B -> claim class C
Preserve(T, P)
```
P names semantic, causal, measurement, provenance, or uncertainty properties that must survive T.

This potentially unifies measurement validity, causal abstraction, model equivalence, semantic losslessness, counterfactual invariance, transportability, ontology evolution, and evidence provenance.
