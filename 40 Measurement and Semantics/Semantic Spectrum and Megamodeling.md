# Semantic Spectrum and Megamodeling

Semantic spectrum:
```text
text -> controlled vocabulary -> glossary -> taxonomy -> thesaurus -> conceptual schema -> typed knowledge graph -> formal ontology -> axiomatized ontology with inference semantics
```
Ontology engineering determines what semantic structure is needed; the spectrum describes the degree of explicit/formal semantics.

A **metamodel** specifies what kinds of model elements exist and how they relate. A **megamodel** models relationships among models, metamodels, transformations, representations, methods, and artifacts.

This is directly relevant to an architecture containing semantic IRs, DAG projections, observation models, process-tracing methods, execution tools, results, and claims.
