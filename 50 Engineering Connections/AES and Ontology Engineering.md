# AES and Ontology Engineering

The Agentic Engineering System analogy:

| Ontology engineering | AES |
|---|---|
| Competency question | Success criterion |
| Domain requirement | Normative item |
| Counterexample | Disproof condition |
| Required observation | Evidence requirement |
| Class/relation structure | Typed target record/ref |
| Axiom/invariant | Validator rule |
| Ontology instance | Concrete target entry |
| Reasoner/consistency check | validate/reconcile/status |
| Ontology evolution | plan prepare/validate/accept |

Shared anti-speculation principle: introduce a new primitive/component only when an explicit competency question or gap cannot be satisfied cleanly by existing constructs/capabilities. This suggests using AES-like planning and evidence discipline to govern ontology construction itself.
